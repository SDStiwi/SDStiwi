How a sensor reading travels through BoviSense

A simple look at the path data takes in my graduation project.

  1. Sensor node ESP32 with sensors, on the animal
  2. LoRa link Long-range, low-power radio hop
  3. Edge node Collects and forwards readings near the farm
  4. MQTT and TLS Secure telemetry transport
  5. Cloud Receives, processes and serves the data
  6. Dashboard React interface for monitoring

Project

Graduation project, 2025–2026

BoviSense

Smart Cattle Health Monitoring System

An IoT system for monitoring cattle health using ESP32-based sensor nodes, LoRa communication, MQTT with TLS, edge processing and a React dashboard. The prototype was tested under real cattle conditions, including sensor placement, telemetry acquisition and LoRa communication.
